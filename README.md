# Strona internetowa

Nowoczesna, responsywna strona internetowa wykonana w HTML5, SCSS i JavaScript (ES6+).
**🌐 Live:** [Zobacz stronę](https://lessyl.github.io/Sylwialesner.pl/)

## Technologie

- HTML5
- SCSS / Sass
- JavaScript ES6+
- Responsive Web Design
- Semantyczny i dostępny HTML

## Struktura projektu

- `project/html/` – pliki HTML/Kit
- `project/src/sass/` – style źródłowe SCSS
- `project/src/js/` – kod źródłowy JavaScript
- `dist/css/` – skompilowane i zminifikowane pliki CSS
- `dist/js/` – skompilowane i zminifikowane pliki JavaScript
- `dist/img/` – obrazy wykorzystywane na stronie

## Funkcje

- responsywny układ Mobile First
- sekcja Hero z interaktywnym podglądem realizacji
- przełącznik prezentowanych projektów
- sekcje prezentujące ofertę i korzyści
- sekcja kontaktowa
- animacje i efekty wizualne
- dostosowanie do urządzeń mobilnych i dużych ekranów

## Realizacje

W podglądzie strony prezentowane są trzy przykładowe realizacje:

- Kwiaciarnia
- Usługi ziemne
- Apartament

## Uruchomienie

Otwórz plik `index.html` w przeglądarce lub uruchom projekt za pomocą lokalnego serwera.

## Założenia

Projekt został przygotowany z naciskiem na prostotę, czytelność kodu, responsywność oraz nowoczesny wygląd.
